lucky-canvas

基于 JavaScript 与 Canvas 的大转盘、九宫格、老虎机抽奖组件，用简单配置实现自由定制，快速完成营销活动需求。

开始体验文档实验室 查看 GitHub
GitHub 仓库 · Gitee 镜像

自由配置

奖品、文字、图片、颜色与按钮均可配置，支持同步或异步抽奖，中奖概率可由前后端控制。

多端适配

支持 JS、Vue、React、微信小程序、UniApp、Taro 等环境，并保持一致的使用体验。

响应式清晰度

自动根据设备 DPR 调整清晰度，同时支持百分比、rem、rpx 等单位适配不同布局。

正在构建

把文档变成可实时调试的实验室

调整参数、即时查看抽奖效果、同步生成代码，并可通过链接分享当前配置。
